# Roadmap

Feature requests, planned work and implementation decisions are tracked in
[GitHub issues](https://github.com/dariuszpanas/iperf3-lib/issues).

- [Browse open proposals](https://github.com/dariuszpanas/iperf3-lib/issues?q=is%3Aissue%20is%3Aopen%20label%3Aenhancement)
- [Suggest a feature or report a problem](https://github.com/dariuszpanas/iperf3-lib/issues/new/choose)
- [Read release history](changelog.md)

For current behavior and supported features, use the [API reference](reference/api.md)
and [compatibility guide](reference/compatibility.md).
Historical planning and design notes are kept in the repository's
[development documentation](https://github.com/dariuszpanas/iperf3-lib/tree/main/development).
