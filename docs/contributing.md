# Contributing

Bug reports, documentation improvements and focused pull requests are welcome.
Use [GitHub issues](https://github.com/dariuszpanas/iperf3-lib/issues) to describe
problems or discuss proposed changes.

The repository's [contributor guide](https://github.com/dariuszpanas/iperf3-lib/blob/main/CONTRIBUTING.md)
covers setup, checks, native testing and the review process. Maintainers can find
release procedures and design notes in the
[development documentation](https://github.com/dariuszpanas/iperf3-lib/tree/main/development).

For a potential security issue, follow the [private reporting instructions](security.md).
